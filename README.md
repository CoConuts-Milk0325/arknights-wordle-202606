# 猜！干！员！ (Arknights Wordle)

《明日方舟》主题的猜干员小游戏，根据干员的星级、职业、属性数值、阵营、出身地等多维度线索逐步推测目标干员！

🌐 **在线试玩地址**：[https://arknights-wordle-202606.pages.dev/](https://arknights-wordle-202606.pages.dev/)  
📱 **移动端小头模式（森拉鉴定大师课毕业考试）**：[https://arknights-wordle-202606.pages.dev/bw/index.html](https://arknights-wordle-202606.pages.dev/bw/index.html)

---

## 🎮 游戏模式

本项目支持多种富有趣味性和挑战性的猜测模式：

1. **大头模式（基础档案）**
   - 包含线索：性别、星级、职业、国家、种族、源石技艺适应性、身高、感染状态、出生日期、标签。
   - 绿色代表完全匹配，黄色代表部分重合（如生日同月/同日，部分标签重叠）。

2. **兔头模式（硬核数值）**
   - 包含线索：星级、满级攻击、满级生命、满级防御、满级法术抗性、攻击间隔、上线年份、标签。
   - 提供数值大小方向箭头（`↑` / `↓`）以及差距接近程度提示（`close` / `far`）。
   - 支持设置“满潜”与“满信赖”数值加成对比。

3. **小头模式（像素立绘猜干员）**
   - 从高度模糊/像素化的马赛克立绘开始，随着错误猜测次数逐步细化方块，还原干员立绘。

4. **真·小头模式（局部放大猜干员）**
   - 从干员立绘的微小局部区域开始，随着猜测推进逐步向外扩大视野范围。

5. **猜技能模式**
   - 随机抽取一名干员的主动技能图标，根据技能图标图像与阶段性提示推断技能所属干员。

6. **📱 移动端小头独立专版 (`/bw/`)**
   - 针对手机触屏专门优化的独立版页面，支持双指自由缩放和平移立绘，沉浸式暗色界面与结语评级。

## 💡 便捷功能

- **指定目标测试**：URL 支持添加 `?target=干员名` 参数直接锁定本局目标（例如：`https://arknights-wordle-202606.pages.dev/?target=结城理`）。
- **拼音智能搜索**：干员搜索输入框全面支持汉字、全拼、无空格拼音、声母首字母缩写检索（如输入 `jcl` 匹配 `结城理`）。
- **主题切换**：支持浅色/深色主题自由切换，状态持久化保存。

## 🛠 技术栈与架构

- **前端框架**：Vue 3 (Composition API) + Vue CLI
- **图片与媒体资源**：PRTS Wiki (MediaWiki CDN 动态 MD5 散列寻址)
- **拼音处理**：`pinyin-pro`
- **构建部署**：Webpack + Cloudflare Pages

## 💻 本地开发

### 环境要求
- Node.js >= 16.0.0
- npm / yarn

### 运行步骤

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动本地开发服务器 (默认端口 8080，支持指定端口)
npm run serve
# 或指定端口:
npm run serve -- --port 8088

# 代码规范检查
npm run lint

# 生产环境打包构建 (输出至 frontend/dist)
npm run build
```
